Hospital Management Backend And Database Notes
==============================================

Why sign-in was failing
-----------------------
The latest backend log shows this error:

MongooseServerSelectionError: connect ECONNREFUSED 127.0.0.1:27017

That means the API cannot connect to MongoDB. Login depends on the User collection in MongoDB, so signing in will fail until MongoDB is running and the seed data exists.

How to start locally
--------------------
1. Install dependencies from the project root:
npm install

2. Start MongoDB locally.
If MongoDB is installed as a service, start the MongoDB service from Windows Services.
If using Docker only for MongoDB, run:
docker compose up -d mongo

3. Seed the database:
npm run seed

4. Start the backend API:
npm run dev:api

5. Start the frontend web app in another terminal:
npm run dev:web

How to test login with PowerShell
---------------------------------
After MongoDB is running, the database is seeded, and the API is started, run:

Invoke-RestMethod -Method Post -Uri http://localhost:4000/api/auth/login -ContentType "application/json" -Body '{"email":"admin@hospital.local","password":"Password@123"}'

Expected result:
The response should include user, accessToken, and refreshToken.

Common problems
---------------
Problem:
Backend shows ECONNREFUSED 127.0.0.1:27017.

Fix:
MongoDB is not running or MONGODB_URI points to the wrong host. Start MongoDB or update apps\api\.env.

Problem:
Login says invalid email or password.

Fix:
Run npm run seed, then use one of the seed emails above with Password@123.

Problem:
Frontend cannot reach backend.

Fix:
Make sure apps\web\.env has VITE_API_URL=http://localhost:4000/api and the API is running on port 4000.

Problem:
CORS error in browser.

Fix:
Make sure apps\api\.env has CLIENT_ORIGIN=http://localhost:5173,http://127.0.0.1:5173 for local Vite development.
